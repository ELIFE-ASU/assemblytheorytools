# `assemblytheorytools`

The package source. Each module is documented in the
[API reference](https://assemblytheorytools.readthedocs.io/en/latest/modules.html);
the narrative documentation lives in `docs/`, and runnable examples in
`examples/`.

`data/` holds the two files shipped with the package: the precomputed
integer-chain lookup table behind `calculate_integer_chain`, and the reference
molecule set the test suite checks against.
